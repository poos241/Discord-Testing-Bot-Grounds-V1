Settings — {{ guild_name }}

Two tabs, one page. The Permissions tab holds the same rules Discord /perm manages: one row grants (or denies) one action to one role or one user. The Logger Settings tab holds the log channels, event toggles, and automod. Only the server owner and Emily can always get in; everyone else needs the matching action (web:manage_permissions for Permissions, web:manage_logs for Logger Settings) to see a tab.

Unverified role

Members holding this role are treated as unverified: they cannot open any server dashboard page until RaidProtect removes the role (when they solve the captcha). Leave it empty when the server has no unverified role.

Bypass users

These users can open any server's site without needing any permission at all — no dashboard grant, no section grant, and the unverified role never blocks them. Add someone here when they should always get in. The two permanent bypass users (Emily and the Little Haven owner) cannot be removed.
