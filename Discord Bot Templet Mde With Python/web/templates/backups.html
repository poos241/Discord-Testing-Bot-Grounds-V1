Backups

Snapshots of the bot's data: bot.db, message_log.db, and the JSON data files (mod data, watchlist, Eat It or Yeet It data). A snapshot is taken automatically every day at {{ "%02d:00" % scheduled_hour }} PC local time, and you can take one by hand any time before a risky change.

Restoring is moderator-only and always takes a pre-restore safety snapshot first, so a restore can itself be undone. After restoring, restart the bot so every cog picks up the restored data. Retention: the newest 14 daily snapshots plus the newest 10 manual / pre-restore snapshots are kept.

Not backed up on purpose: notification read-state (dismissing a notification is not bot data) and debug logs.
