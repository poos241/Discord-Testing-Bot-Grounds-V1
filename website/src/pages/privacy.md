# Privacy Policy — Havenly Backups

Last updated: November 13, 2026.

Havenly Backups is a small, personal-use application that backs up the database of the Havenly Bot (a Discord bot) to the owner's own Google Drive account.

## What the app does

Havenly Backups copies a database backup file (a database dump) from the server that runs the Havenly Bot and uploads it to a folder in the owner's Google Drive. The upload runs automatically on a schedule. The backup file is encrypted before it is uploaded, so its contents cannot be read from Google Drive without the encryption password.

## What data the app accesses

- **Google Drive:** The app accesses Google Drive only to upload the backup file to a folder the owner controls. It does not read, download, or modify any other files in the Google Drive account.
- **The backup file:** The backup contains the Havenly Bot's database (server configuration, moderation records, and user profiles stored by the bot). It is encrypted before upload and is only ever stored in the owner's own Google Drive.

## What the app does not do

- It does not collect personal information from anyone.
- It does not share, sell, or disclose any data to any third party.
- It does not track users, show advertising, or use analytics.
- It is for the owner's personal use only and is not offered as a service to anyone else.

## Data retention

Backup files remain in the owner's Google Drive until the owner deletes them. The app itself stores no user data.

## Contact

Havenly Backups is operated by the owner of the Havenly Bot for their own personal use. Questions about this app can be raised through the Havenly Bot project on GitHub at https://github.com/poos241/Discord-Testing-Bot-Grounds-V1.
